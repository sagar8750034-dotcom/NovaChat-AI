# Simple Chatbox App

A static chat UI built with HTML, CSS, and JavaScript.

## Files
- `index.html`: chat interface markup
- `styles.css`: styling for the chat app
- `script.js`: message handling and placeholder Gemini integration logic

## Run locally
Open `index.html` in your browser.

## Gemini integration
This app currently uses a placeholder `botReply()` function.
To connect with Google Gemini, implement a backend endpoint that calls Gemini and update `fetchGeminiResponse()` in `script.js`.
